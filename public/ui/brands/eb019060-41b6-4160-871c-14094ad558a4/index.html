    Each scan searches the first 10 queries in US (en): up to 6 Google searches (SerpApi, about $0.06). Scheduled scans are off on this server, so Google is searched only when someone starts a scan. Every result is triaged before it is visited: the brand's own site and well-known platforms are skipped.

    Automatic scans · ShopNova is scanned again by itself, as often as you choose, doing only what you tick

    This server does not run automatic scans — its scheduler is off (SCHEDULER_ENABLED). The live server's start script switches it on; what you set here is saved either way.

    Paid calls (Google search, Facebook / Instagram ads and accounts) count against the workspace's daily spend limit; DNS, certificate logs, new domains and urlscan are free. Every automatic scan appears under “Recent scans” with its own console.
