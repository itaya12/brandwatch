Provider alerts · limits, bad keys, outages — and what to do

No provider problems so far.
what would appear here — and how BrandWatch copes

Every provider call goes through: TTL cache → budget check → circuit breaker → token bucket → retry with backoff (Retry-After honoured) → the next provider in the fallback chain. Each problem becomes one alert with a plain-language fix:

siteVirusTotal: a site or account did not answer
Only that one target is affected — its evidence is marked unavailable and the scan went on; it is re-checked on the next scan. Nothing to fix. ({error})
quotaDaily budget reached
The workspace's daily limit (API calls or spend) is used up, so VirusTotal is skipped for the rest of today. Raise the limits under Settings → Workspace & budget, or run the scan again tomorrow.
creditsVirusTotal: the account has no requests left
The provider answered that this account's requests are used up (a free trial ends after its first requests), so VirusTotal is skipped. Top up or choose a plan on the provider's site; the key in Settings → API keys stays the same. Waiting does not help. ({error})
rate limitVirusTotal: rate limit hit
The provider asked us to slow down (retry after 60 s). Free plans allow only a few requests per minute, so some candidates have no VirusTotal evidence. Re-run the scan later or upgrade the plan.
authVirusTotal: API key rejected
The provider refused the key — it is invalid or expired, or the account has no active (free) subscription for this product yet. Check the provider's dashboard, then paste the key again under Settings → Provider API keys and re-run the scan.
outageVirusTotal: temporarily unavailable
The service answered with a server error, so it is down or overloaded right now (crt.sh does this often). Nothing to fix on your side — the next scan retries it automatically; its evidence is marked unavailable for now.
circuitVirusTotal: paused after repeated failures
Several errors in a row, so the provider is skipped for a short cooldown. Check the provider's status page; its evidence is marked unavailable meanwhile.
not configuredNo provider for reputation
Add an API key for one of: virustotal, urlhaus under Settings → Provider API keys. The scan continues without this evidence.
networkVirusTotal: network problem
Timeout or connection error (already retried). Check the internet connection or the provider's status; the affected evidence is marked unavailable.
fallbackVirusTotal unavailable — URLhaus answered instead
The chain recovered on its own: nothing to do. "Unknown" is never treated as clean.
